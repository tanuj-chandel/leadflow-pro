Section 2

Lead Scraping & Phone Intelligence Engine

The data collection pipeline is designed with a strict Zero Fake Data policy. It operates in multiple cascading phases to guarantee authentic business names, verified contact info, and high delivery rates.

Phase 1: Google Places API (New) Extraction

When a search is launched (e.g. "Private Dental Clinics in London, UK" or "Real Estate Agencies in Dubai, UAE"), the engine calls Google's latest v1 Places API endpoint: 

POST https://places.googleapis.com/v1/places:searchText
Headers:
  Content-Type: application/json
  X-Goog-Api-Key: [API_KEY]
  X-Goog-FieldMask: places.displayName,places.formattedAddress,places.nationalPhoneNumber,
                    places.internationalPhoneNumber,places.websiteUri,places.rating,
                    places.id,nextPageToken
Body:
  { "textQuery": "Real Estate Agency in Dubai, UAE", "pageSize": 20 }
Pagination & Rate Control: If more than 20 leads are requested (e.g., 50 leads), the engine tracks nextPageToken, pauses for 1,500ms to allow Google token registration, and cycles through consecutive pages until the quota is satisfied.

Phase 2: Deep HTML Website Crawler

For every business that has an official website listed on Google Maps, the scraper runs an autonomous multi-page crawler across /, /contact, /about, and /reach-us.

  1. Direct Business Emails: Uses regular expressions combined with domain blacklists to capture authentic corporate inboxes.
  2. WhatsApp Click-to-Chat Numbers: Scans for wa.me/<number> and api.whatsapp.com/send?phone=<number> embedded in chat widgets. This captures direct mobile phones even when the Google Maps listing displays an office landline!
  3. Social Proof Profiles: Automatically pulls links to Instagram, LinkedIn company pages, Facebook, and Telegram channels.

Section 3

Autonomous Multi-Channel Outreach Systems

📲 1. WhatsApp Automation Client

Underlying Engine: Headless Chromium via Puppeteer with WhatsApp Web interface.

  • Human Typing Emulation: Triggers realistic typing presence for 600–1,400ms prior to dispatching messages.
  • LID & JID Pre-Verification: Queries client.getNumberId() to confirm registration before sending.
  • Anti-Detection Stealth: Modern desktop User-Agent, disabled AutomationControlled blink feature.
  • Auto-Recovery Watchdog: Automatically clears stale locks (DevToolsActivePort, SingletonLock) and self-heals in 5s.

✈️ 2. Telegram UserBot (MTProto GramJS)

Underlying Engine: GramJS MTProto client operating directly as Tanuj Chandel's authenticated account.

  • Phone-to-Entity Resolution: Resolves cold business numbers through Api.contacts.ImportContacts before messaging.
  • Permanent SQLite Session: Session string stored in SQLite settings; never requires re-authentication.
  • Anti-Flood Throttler: Automatically spaces consecutive messages with randomized 15–25s pauses.
  • 1-Tap & Bulk Execution: Accessible via individual row buttons and bulk operations bar.

✉️ 3. Gmail API OAuth2 Engine

Underlying Engine: Google APIs Node.js Client with token persistence.

  • 1-Click Draft Generation: Creates fully personalized drafts directly in founder's Gmail inbox.
  • Dynamic Placeholders: Injects {{BusinessName}}, {{Location}}, {{Rating}}.
  • Human-in-the-Loop Safety: Drafts are created for review, giving 100% control over tone and timing.

🔔 4. Real-Time Telegram Founder Alert Bot

Underlying Engine: Telegram Bot API integrated with SSE event listeners.

  • Instant Inbound Alerts: Whenever a client replies on WhatsApp or Telegram, an instant alert is pushed to founders.
  • OpenAI Suggested Reply: Analyzes the inquiry and generates an AI draft response ready for 1-tap dispatch.
  • 1-Tap Quick Action Links: Direct wa.me deep links and tel: links included in every notification.

Endpoint Method Description & Payload

/api/logs/stream GET Server-Sent Events (SSE) stream broadcasting real-time logs to the UI.
