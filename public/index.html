Google Developer Setup Guide
  1. Go to the Google Cloud Console.
  2. Create a Project and enable **Gmail API**, **Google Sheets API**, and **Google Drive API**.
  3. Configure the **OAuth Consent Screen** (User Type: External / Testing, add your email as test user).
  4. Go to **Credentials** > **Create Credentials** > **OAuth Client ID** (Application Type: Web Application).
  5. Add `http://localhost:3000/oauth2callback` to **Authorized Redirect URIs**.
  6. Copy Client ID and Client Secret, paste them into settings, and click Connect.
